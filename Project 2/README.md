
**Title:** BST and AVL Height and Search Comparison

**Description:** A C++ program that constructs a Binary Search Tree (BST) and an AVL tree using the same input elements and compares their heights and search comparisons. It tests ascending, descending, and random insertion orders to analyze the effect of tree balancing on search efficiency.

**Data Structure:** Binary Search Tree (BST), AVL Tree

**Operations:**

* Insertion
* Searching
* Height Calculation
* AVL Rotations and Balancing
* Counting Search Comparisons
* Performance Comparison

**Language:** C++
