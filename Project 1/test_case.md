## 1.Test Cases: BST and AVL Height Comparison

Test Case 1: Ascending Order

Input:

10 20 30 40 50

Expected Output:

- BST becomes right-skewed.
- AVL tree balances itself automatically.
- BST height is greater than AVL tree height.
- Search comparisons are counted for the same keys in both trees.

## 2.Test Case 2: Descending Order

Input:

50 40 30 20 10

Expected Output:

- BST becomes left-skewed.
- AVL tree balances itself automatically.
- BST height is greater than AVL tree height.
- Search comparisons are counted for the same keys in both trees.

## 3.Test Case 3: Random Order

Input:

30 10 50 20 40

Expected Output:

- Both trees are constructed using the same input sequence.
- Heights of the BST and AVL tree are calculated.
- Search comparisons are counted for the same keys in both trees.
- The results are compared to analyze search efficiency.

## Conclusion

These three test cases compare BST and AVL tree heights and search comparisons for ascending, descending, and random insertion orders.
