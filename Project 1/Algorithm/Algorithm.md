## Algorithm

1. Start the program.
 
2. Define a node containing account number, customer name, account type, balance, previous pointer, and next pointer.
  
3. Initialize the head pointer to NULL.
  
4. Display the menu of available operations.
 
5. Accept the user's choice.
  
6. Perform the selected operation:

7. 
   -Add Account: Create a new node and insert it into the list.

   -Display Accounts: Traverse the list and display all account details.
   
   -Search Account: Search for an account using its account number.
   
   -Delete Account: Remove the specified account and update the links.
   
   -Update Balance: Search for the account and update its balance.
     
9. Repeat the menu until the user selects Exit.

10. Release the dynamically allocated memory.
  
11. Stop the program.
