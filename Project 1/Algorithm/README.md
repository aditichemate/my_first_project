## Algorithm

1. Start.
2. Initialize the head pointer to NULL.
3. Display the bank account management menu.
4. Accept the user's choice.
5. If the choice is Add Account, create a new node and enter account details.
6. Insert the new node into the doubly linked list by updating the previous and next pointers.
7. If the choice is Display, traverse the list and display all account details.
8. If the choice is Search, find the account using its account number.
9. If the choice is Deposit, add the entered amount to the account balance.
10. If the choice is Withdraw, check the balance and deduct the amount if sufficient funds are available.
11. If the choice is Delete, remove the selected account and update the links.
12. Repeat the menu until the user selects Exit.
13. Free the dynamically allocated memory.
14. Stop.
