Algorithm: Bank Account Management System

Step 1: Start the program.

Step 2: Initialize the head and tail pointers to NULL.

Step 3: Display the main menu:

1. Add Account
2. Display Accounts Forward
3. Display Accounts Backward
4. Search Account
5. Deposit Money
6. Withdraw Money
7. Delete Account
8. Exit

Step 4: Accept the user's choice.

Step 5: Perform the selected operation.

- Add Account: Accept account details, create a new node, and insert it into the doubly linked list.
- Display Forward: Traverse the list from head to tail and display all account records.
- Display Backward: Traverse the list from tail to head and display all account records.
- Search Account: Search for the account using its account number.
- Deposit Money: Find the account and add the deposit amount to its balance.
- Withdraw Money: Find the account and check whether the balance is sufficient before deducting the amount.
- Delete Account: Find the account, update the surrounding pointers, and delete the node.
- Exit: Terminate the program.

Step 6: If the selected operation is not Exit, return to Step 3.

Step 7: Release any remaining dynamically allocated memory.

Step 8: Stop the program.
